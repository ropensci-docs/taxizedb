# Load taxonomic databases

This family of functions has been removed. Use
[db_download](https://docs.ropensci.org/taxizedb/reference/db_download.md)
then
[src_taxizedb](https://docs.ropensci.org/taxizedb/reference/src_taxizedb.md).

## Usage

``` r
db_load_itis(...)

db_load_tpl(...)

db_load_col(...)

db_load_gbif(...)

db_load_ncbi(...)

db_load_wikidata(...)
```

## Arguments

- ...:

  ignored

## Value

An error message.
